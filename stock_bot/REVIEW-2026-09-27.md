# Stock bot review — 2026-09-27

A second chat's review of the code as of master `262c411`. Nothing was
changed; every bug below was reproduced by running the real functions.
Ranked by how soon it bites.

## 1. Momentum robot crashes at its close check once it owns anything

`momentum_bot.daily_check()` passes `broker.positions()` to `decide()`.
`PaperBroker.positions()` returns only symbol / qty / avg_entry_price /
market_value — the `peak` and `trail` the robot stored are dropped — so
`decide()` raises `KeyError: 'trail'` (and even with a default, `peak`
would fall back to today's price and the trailing stop could never fire
at the close).

Reproduced: a practice account holding one stock with peak/trail set →
`decide(cfg, data, broker.positions(), ...)` → `KeyError 'trail'`.

Effect: first buy lands at a close check; at the next close check the
loop fails 10 times, texts "Momentum robot: stopped", exits, and the
queued run repeats it. No more close-check sells or buys. The mid-day
guard still works because it reads `broker.acct["positions"]` directly.
The selftest misses it because it hands `decide()` hand-built positions.

Fix: give `decide()` the stored positions merged with market values, and
add a selftest that goes through a real `PaperBroker`.

## 2. Dip robot: stop-losses are blocked by the daily order cap

`stock_bot.decide()` only sells while `orders_left > 0`. On a market-wide
drop the dip rules can use all 8 orders on buys; after that a stock
already down past its stop-loss is not sold until the next day.

Reproduced: 8 orders used today, HOOD down 15% with a 10% stop → `[]`.
With 7 used → sells.

Fix: the cap limits buys only; protective sells always go.

## 3. Dip robot: a held stock taken off the list is orphaned

`check()` prices and `decide()` checks only the stocks on the watchlist.
Remove a stock you still hold and it is never sold (no stop-loss, no
take-profit), and the practice broker values it at its purchase price
forever, so account value and the vs-SPY line go wrong.

Reproduced: PFE held, removed from the list, down 40% → `[]`.

Fix: always price everything held; apply the last known rules (or the
default 8/20/10) to held stocks that left the list.

## 4. Late starts (likely — check Monday)

NOTE in ecs-daily-post.yml). The dip robot's first start is 13:05 UTC; if
it lands that late, it watches only the afternoon — or the last hour.
Unverified: neither stock workflow has run on a weekday yet.

Fix if late: earlier and more start times, off round minutes, and let
